# BayesianBenter: Bayesian Estimation of the Benter Model for Rankings

An efficient Gibbs sampler for Bayesian inference in the Benter model
for ranking data, a generalization of the Plackett-Luce model that
introduces stage-specific dampening (noise) parameters. Estimation uses
exponential and alpha-stable data augmentation that preserves conjugacy,
giving exact Gamma draws to worth parameters and MH updates of dampening
parameters. Both complete and partial (top-R) rankings are supported.
